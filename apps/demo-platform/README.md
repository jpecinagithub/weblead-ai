# @weblead/demo-platform

Vite + React + TS static multi-business demo platform (Phase 0 skeleton).

- Route: `/demos/{slug}` (slug = slugified pilot-lead name, e.g.
  `/demos/fontaneria-la-moderna`).
- Every page shows the visible conceptual notice: "Propuesta conceptual
  independiente, no oficial y pendiente de autorización de la empresa."
- Phase 0 renders structure only — no real website content yet (Phase 2).

```sh
pnpm --filter @weblead/demo-platform dev  # → http://localhost:5174
```
