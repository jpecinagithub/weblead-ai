# @weblead/website-templates

Two real, differentiated sector templates (Fase D) — not one generic
template with different colours.

- `fontaneria-climatizacion`: petrol-blue + copper, condensed headings,
  trust first, "Cómo trabajamos" section, plumbing FAQ, 3 plumbing photos.
- `peluqueria-barberia`: charcoal + gold, serif display headings, gallery
  first, hair FAQ, 3 hair photos.
- Photos: Unsplash License, visually verified 2026-11-16, served locally
  from `apps/demo-platform/public/images/` (the VM browser cannot reach
  images.unsplash.com); provenance kept in `sourceUrl` + `WebsiteAsset`.
