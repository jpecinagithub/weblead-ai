# WebLead AI — Master Prompt v1.0 (recibido 2026-11-16)

Proyecto: WebLead AI – Autonomous Digital Agency. SaaS interna de agentes autónomos, mercado España, idioma español, todos los sectores, priorización por potencial de contratación. Autonomía en investigación/desarrollo/auditoría; comercial con aprobación humana y controles legales previos. Presupuesto mínimo coste, preferencia modelos gratuitos/económicos, reutilizar servicios existentes, hosting Vercel, backend persistente posible en Oracle Linux existente. No contratar servicios de pago automáticamente ni activar APIs de pago sin que el admin conozca su coste.

## Misión
Investigar empresas españolas, detectar sin web propia o con presencia deficiente, comprobar existencia y señales recientes de actividad, identificar oportunidades, crear webs personalizadas elaboradas, identidad visual/logos conceptuales/imágenes, desplegar demos en Vercel, auditarlas, preparar propuestas comerciales, gestionar contactos/respuestas por Gmail, control desde dashboard centralizado. No una demo visual: un sistema operativo. No inventar funcionalidades terminadas: implementar, comprobar, documentar limitaciones.

## Agentes (6 lógicos, contrato estructurado común)
- 0 ORCHESTRATOR: campañas, trabajos, asignación, dependencias, errores/reintentos, presupuestos, estados, decisiones, parada. Máquina de estados persistente, transiciones validadas en backend, sin saltos arbitrarios. Estados: DISCOVERED, RESEARCHING, RESEARCHED, QUALIFIED, REJECTED, DESIGNING, PREVIEW_READY, AUDITING, AUDIT_FAILED, APPROVED, SALES_PENDING, SALES_APPROVED, CONTACTED, REPLIED, NEGOTIATION, WON, LOST, ARCHIVED. Admin puede detener campaña y cancelar pendientes.
- 1 RESEARCHER: fuentes legales/accesibles (Google Search, OpenStreetMap, directorios con ToS compatibles, registros oficiales, BORME, webs corporativas, redes públicas, directorios sectoriales, APIs autorizadas). Google Maps solo como referencia conforme a sus condiciones. NO scraping masivo de Google Maps ni base independiente sin autorización. Proceso 12 pasos (provincia/municipio, sectores, buscar, nombre/actividad/ubicación, existencia, web propia, presencia digital, señales recientes, teléfono/contacto público, fuentes+fecha, evaluar, informe). Actividad: CONFIRMED / PROBABLE / UNVERIFIED / INACTIVE (ausencia de info ≠ inactividad). Scoring 0-100: sin web 25, actividad verificada 25, necesidad digital 20, contactabilidad 15, potencial económico 15. Umbral 70. Sin evidencias suficientes no pasa a producción web. Expediente estructurado con fuente por dato, null si desconocido, sin inventar.
- 2 WEB DESIGNER/DEVELOPER: Fase A investigación creativa, B identidad visual (logo conceptual, paleta, tipografía, estilo foto, guía; no marcas de terceros; logos como propuestas conceptuales), C imágenes (proveedores gratuitos/económicos, originales o bancos con licencia compatible, no de competidores, guardar procedencia/licencia), D construcción (responsive, home elaborada, servicios, empresa, galería, CTAs, contacto, formularios, WhatsApp si procede, SEO, metadatos, sitemap, robots, optimización imágenes, accesibilidad, avisos legales demo; funcionalidades sectoriales: reservas, presupuesto, catálogos, portfolios, calculadoras, FAQ, fichas; no servicios de pago sin autorización; no precios/horarios/testimonios/acreditaciones no contrastados; datos ficticios identificados), E plataforma multiempresa /demos/{slug}, datos aislados, aviso visible "Propuesta conceptual independiente, no oficial y pendiente de autorización de la empresa.", no publicar como web contratada, no formularios que envíen a terceros sin autorización.
- 3 AUDITOR: independiente del desarrollador. Auditoría empresarial, contenido, visual, técnica con Playwright (home, navegación, enlaces, formularios, imágenes, errores consola/HTTP, móvil/escritorio, rendimiento, accesibilidad, SEO, disponibilidad, capturas). Informe con puntuaciones empresarial/visual/técnica/contenido, errores críticos/menores, recomendaciones, resultado. Fallo → vuelve al desarrollador. Sin aprobación de auditoría no hay paso comercial.
- 4 SALES: Gmail OAuth permisos mínimos. Recibir expedientes, analizar, consultar demo, preparar propuesta/presupuesto, correo personalizado, borradores en Gmail, registrar actividad, consultar respuestas, clasificar leads, preparar respuestas, seguimiento. Presupuestos configurables por variables (complejidad, páginas, diseño, logo, imágenes, formularios, reservas, integraciones, SEO, mantenimiento, hosting, dominio). Modalidades BASIC/PRO/PREMIUM orientativas, precios configurables, no ofertas definitivas sin validación. Política: NO emails masivos ni no solicitados sin base legal. Antes de enviar comprobar destinatario, finalidad, base jurídica, LSSI, consentimiento/excepción, procedencia, oposición/baja, exclusión. Correo público ≠ autorización. Sin base válida: oportunidad interna, propuesta interna, contacto no autorizado, no enviar. Admin revisa/aprueba cada borrador; aprobación humana no sustituye obligación legal. Respuestas: INTERESTED, REQUEST_PRICE, REQUEST_INFORMATION, NEGOTIATION, NOT_INTERESTED, UNSUBSCRIBE, COMPLAINT, OTHER. Respuestas sugeridas; no enviar automáticamente compromisos económicos/contratos/respuestas sensibles sin aprobación.
- 5 CRM / CUSTOMER SUCCESS: pipeline, seguimiento, clasificación, recordatorios, histórico, conversión, estadísticas, informes. Estados: NEW, QUALIFIED, DEMO_CREATED, AUDITED, PROPOSAL_READY, AWAITING_APPROVAL, CONTACTED, RESPONDED, INTERESTED, NEGOTIATION, CUSTOMER, LOST, SUPPRESSED. Histórico de interacciones. Gestionar bajas/oposición. No volver a contactar a quien pidió no recibir comunicaciones.
